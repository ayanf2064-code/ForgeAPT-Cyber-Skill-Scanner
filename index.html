About ForgeAPT

Built for small elite teams (5–10 people) who want to grow together like a real APT group — structured, practical, zero fluff.

The Idea

After watching CyberMindSpace (Almadad Ali Sir) modules, the team realised that everyone claims “I’m 100% ready”. This scanner forces truth. You take the test → the system tells you exactly where you are weak (Linux, Networking, Web, AI, Tools…) → the whole team starts learning from the lowest common level. No one left behind.

Why This Project is Unique

  • Three distinct evaluation modes in one tool
  • Category-level diagnosis (not just total score)
  • Hint system with real penalty (exam realism)
  • Pure frontend — runs offline on any machine
  • Designed to be the first project a new team ships together

Modules Covered

Introduction, Footprinting & Recon, Scanning, Enumeration, Vulnerability Analysis, System Hacking (Windows/Linux PrivEsc), Malware, Sniffing, Social Engineering, DoS, Session Hijacking, IDS/Firewalls/Honeypots, Web Server Security, Web App Hacking, SQL Injection, Wireless, Mobile, plus AI security concepts.
